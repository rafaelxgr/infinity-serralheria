# Infinity Serralheria

Landing page responsiva criada para a Infinity Serralheria.

## Estrutura

- `index.html` — conteúdo, SEO e estrutura da página
- `styles.css` — identidade visual escura, azul e responsiva
- `script.js` — menu mobile, galeria ampliada, vídeos sob demanda e botão de topo
- `assets/` — logo, favicon, fotografias e vídeos do cliente
